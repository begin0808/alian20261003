# 國中資訊科技第一單元測驗闖關遊戲 🎮

專為國中七年級資訊科技第一單元（電腦硬體架構、記憶體特性、資訊安全、網路防詐騙與作業系統）設計的清新科技風闖關測驗小遊戲。

## 🌟 特色亮點

- **清新科技風設計**：採用薄荷綠與天空藍清新色系，結合動態科技網格、毛玻璃質感與流暢微動畫。
- **5 大單元核心題庫**：
  1. 電腦硬體架構（CPU 核心元件）
  2. 揮發性記憶體（RAM 特性）
  3. 帳號與密碼資安原則（2FA 與高強度密碼）
  4. 網路防詐素養（識破釣魚簡訊）
  5. 電腦軟體分類（作業系統 OS）
- **互動即時反饋與原生音效**：使用 Web Audio API 原生合成答對/答錯和弦音效，答對薄荷綠高亮，答錯提供「觀念補給站」詳細解析。
- **通關證書與榮譽徽章**：結算總分、榮譽稱號，附帶慶祝五彩紙屑特效與離線高解析度 PNG 證書生成下載。
- **獨立無依賴**：單一 HTML 檔案架構，本地雙擊或任何靜態託管（如 GitHub Pages）皆可秒速執行。
